# Communication Keywords

The keywords **MUST**, **MUST NOT**, **SHALL**, **SHALL NOT**, **SHOULD**, **SHOULD NOT**, and **MAY** are interpreted according to RFC 2119 and RFC 8174.

- **MUST / SHALL** — Mandatory communication behavior.
- **MUST NOT / SHALL NOT** — Absolutely prohibited communication behavior.
- **SHOULD** — Strong recommendation.
- **SHOULD NOT** — Generally prohibited unless justified.
- **MAY** — Optional communication behavior within constitutional and File 01 boundaries.
